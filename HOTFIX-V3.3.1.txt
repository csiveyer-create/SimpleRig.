SimpleRig v3.3.1 loading hotfix

The v3.3 build contained two DOM observers that repeatedly reacted to their own updates. This could lock the browser before the interface rendered.

This hotfix:
- prevents the localisation observer from reacting to text changes made by localisation itself;
- prevents the white-line observer from reacting to its own stroke updates;
- updates asset cache keys to force GitHub Pages and browsers to load the corrected scripts.

Replace all repository contents with this build and hard-refresh once after deployment.
