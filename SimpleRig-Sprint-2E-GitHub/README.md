# SimpleRig — Sprint 2E

Sprint 2E implements functional editing handles.

## Added

- Scale and rotation handles on selected 2D objects
- Independent endpoint handles on Rig Lines
- Improved Rig Line selection
- Dragging a Rig Line moves both endpoints
- Optional 0.25 m grid snapping
- Touch-sized handles
- Undo and redo for handle edits
- Existing recognition, conversion, save/open and 3D view retained

Run with `python3 -m http.server 8000`.

Test with `npm test`.

For GitHub Pages, upload all extracted files to the repository root and choose **GitHub Actions** as the Pages source.
