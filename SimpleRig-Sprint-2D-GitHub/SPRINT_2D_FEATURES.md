# SimpleRig Sprint 2D

This sprint extends sketch recognition into editable geometry.

Implemented in this package:
- Editable recognition metadata structure.
- Object conversion pipeline prepared for handles.
- Shape editing architecture documented.
- Control-point data model reserved for future updates.

Planned editing capabilities:
- Drag recognised line endpoints.
- Resize recognised pulleys by radius handle.
- Rotate recognised objects with rotation gizmo.
- Live snapping to existing rig objects.
- Multi-object selection.
- Box selection.
- Alignment guides.
- Smart duplication.
